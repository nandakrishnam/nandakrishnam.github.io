# nandakrishnam.github.io

Personal website of **Nandakrishna M**, an Offensive Security Consultant and bug bounty hunter from Kerala, India.

**Live site:** https://nandakrishnam.github.io/

## What's on the site

- **About:** bio, experience log and education
- **Focus:** web & API, AI/LLM agent and network pentesting, security reporting, bug bounty & CTFs
- **Certifications:** eJPTv2 (INE), CAP (The SecOps Group), C3SA (CyberWarFare Labs)
- **Hall of Fame:** organisations that have acknowledged my vulnerability reports
- **Blog:** writeups and research notes at [/blog/](https://nandakrishnam.github.io/blog/) ([RSS](https://nandakrishnam.github.io/feed.xml))

## Built with

- Plain HTML, CSS and JavaScript with a terminal-style theme (JetBrains Mono)
- [Jekyll](https://jekyllrb.com/) on GitHub Pages for the blog, SEO tags, sitemap and feed

## Repository layout

```
├── index.html          # homepage
├── 404.html            # terminal-style "not found" page
├── blog/               # blog: one folder per post
│   ├── index.html      # list of all posts
│   └── _template/      # starter post to copy (never published)
├── _layouts/           # page and post templates
├── _includes/          # shared <head> and header
├── assets/             # CSS, JavaScript and images
├── feed.xml            # RSS/Atom feed for the blog
└── _config.yml         # site settings
```
